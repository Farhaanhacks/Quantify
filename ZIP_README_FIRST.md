# Quantifi R2 changes

This ZIP is an overlay for the current Quantifi `main` branch at commit
`f79f9fdd5fc55fba03a96e0da2f1d7228b7db422`.

Copy the included paths over the repository root, run `npm install`, and then
follow `CLOUDFLARE_R2_SETUP.md`.

The package contains only implementation and configuration templates. It does
not contain credentials, downloaded filings, or any HDFC-specific hardcoded
financial figures.
